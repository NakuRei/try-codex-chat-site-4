# ほしぞら通信

2001年で更新が止まった、架空の個人ホームページを探索するブラウザー謎ときゲームです。
LPやポートフォリオではなく、日記・BBS・リンク集・工事中ページを巡って遊ぶサイトです。

## 起動

ビルド不要の HTML / CSS / JavaScript で構成します。ルートの `index.html` が入口です。

```sh
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。

## GitHub Pages

リポジトリの Settings → Pages → Build and deployment で、Source を **Deploy from a branch**、Branch を **main**、フォルダーを **/ (root)** にして保存します。独自の GitHub Actions ワークフローは不要です。

## 方針

- テレホーダイ時代の個人サイトをモチーフにした、オリジナルのフィクションです。
- 謎ときの進行とBBSへの書き込みは、そのブラウザー内だけに保存します。サーバーへの投稿や個人情報の送信は行いません。
- 音は初期状態でOFF。再生操作をした場合のみブラウザー内で合成します。
- 外部ライブラリー・外部フォント・外部画像・解析サービスに依存しません。
