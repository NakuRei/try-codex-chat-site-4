# ほしぞら通信

星と、夜ふかしと、なんでもない日のおはなし。

2001年8月31日で更新が止まった、架空の個人ホームページです。管理人そらの日記や掲示板を読み、リンク先に寄り道できます。あちこちをよく見ると、小さなおまけとタイムカプセルがあります。

## 今回の変更

「古いサイトを模したゲームアプリ」から、「おまけのある昔の個人ウェブサイト」へ寄せました。

- ブラウザー風の外枠、偽アドレスバー、固定ツールバー、常設メニュー、収集状況、探索メモ、獲得ポップアップを削除しました。
- ページ全体をJavaScriptで入れ替える構成をやめ、13個の独立したHTMLファイルにしました。移動は普通のリンクです。
- トップページは自己紹介・コンテンツ表・更新履歴が中心です。謎ときを最初から目的として提示しません。タイムカプセルへの入り口は日記にあります。
- 日記は便せん、BBSは昔の掲示板、リンク集はバナー一覧など、ページごとに体裁を変えました。ねこと音の部屋も独立ページです。
- 五つの仕掛けと、管理人そらの物語は残しました。見つけた文字はページ内の小さな書き込みとして表示します。

## 起動

HTML / CSS / JavaScriptのみ。ビルドやnpm installは不要です。

```sh
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。公開用ファイルはリポジトリのルートにあります。GitHub Pagesの公開設定自体は、この変更では操作していません。

## ページ

| ファイル | 内容 |
| --- | --- |
| `index.html` | ホーム、カウンター、コンテンツ表、更新履歴、おみくじ |
| `profile.html` | 管理人、サイトの説明、ローカル記録の削除 |
| `diary.html` | 日記と、星の飾り |
| `bbs.html` | 掲示板の過去ログとローカル書き込み |
| `links.html` | バナーリンク集 |
| `lost/404.html` | リンク切れの先にある演出用ページ |
| `under_construction.html` | 工事中と消灯の仕掛け |
| `observatory.html` | 星空と光の合図 |
| `secret.html` | タイムカプセル |
| `cat.html` / `music.html` | ねこの休憩所 / 音の小箱 |
| `mail.html` / `help.html` | 管理人への案内 / おまけの説明 |

`style.css` はページ別の装飾、`site.js` はページ内の仕掛けだけを担当します。旧 `app.js` は削除しました。各HTMLは本文とリンクを含み、JavaScriptが無効でも読んで移動できます。おまけの操作やBBS書き込みにはJavaScriptが必要です。

相対パスを使用し、プロジェクト用サブディレクトリーの公開に対応しています。旧版の `#diary` などのブックマークだけは、対応するHTMLへ移動する互換処理を残しています。

## 保存と動作

- カウンター、日付、人物、過去の投稿はフィクションです。実際の訪問者数は集計しません。
- BBSの入力と見つけた文字は、このブラウザーのlocalStorageに保存します。入力内容を外部に送信したり、ほかの訪問者と共有したりしません。
- 旧版と同じ保存キー `hoshizora-tsushin-v1` を使い、同じ公開元・ブラウザーに残る旧記録を引き継ぎます。
- 保存が禁止されている環境ではページ移動後の記録は保持されません。文字を手元に控えれば遊べます。タイムカプセルは合言葉だけで開き、収集フラグを条件にしません。
- 管理人ページで、確認用チェックを入れてから記録を削除できます。
- 音は「おとの小箱」の再生ボタンを押したときだけ鳴ります。Web Audioによるオリジナルの短いメロディーで、MIDIファイルではありません。ページ移動・タブ非表示で停止します。
- 動きを減らす端末設定に対応しています。流れる文字は停止でき、星の合図には番号で見る代替手段があります。
- 外部ライブラリー・外部画像・外部フォント・解析サービスは使用しません。ページ遷移時は同じサイトのHTMLと静的ファイルを読み込みます。

隠しページや合言葉は遊びの仕掛けで、アクセス制限や認証ではありません。ソースを見れば内容や答えがわかります。

検証内容と環境上の制約は `TESTING.md` を参照してください。
