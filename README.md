# ほしぞら通信

> あのころの「また明日」は、まだここにある。

2001年8月31日で更新が止まった、架空の個人ホームページを探索するブラウザー謎ときゲームです。LPやポートフォリオではありません。

管理人の日記、BBS、リンク切れの先、工事中の部屋、夜の展望台。5つのかけらを見つけて、ひみつのページに置かれたタイムカプセルを開いてください。

## 遊び方

トップページの「最後の日記を読んでみる」から始められます。探索の順番は自由で、制限時間やゲームオーバーはありません。右上の「ヒント」から3段階の手掛かりを読めます。3つ目には具体的な解き方が含まれます。

謎とき以外にも、おみくじ、ねこの休憩所、ウェブリング、オルゴール風のBGMなどがあります。

## 起動

HTML / CSS / JavaScriptだけで動作し、ビルドやnpm installは不要です。リポジトリのルートで以下を実行します。

```sh
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。サーバーを終了するにはターミナルで Ctrl+C を押します。

## GitHub Pagesへの公開

リポジトリの **Settings → Pages → Build and deployment** で、以下を指定して保存します。

| 項目 | 設定 |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main |
| Folder | / (root) |

このプロジェクト専用のGitHub Actionsワークフローファイルは不要です。GitHub側のPagesデプロイ処理は実行されます。公開設定の変更はコードのコミットとは別の操作です。

CSS・JavaScript・faviconは相対パスで読み込むため、プロジェクトPagesのサブディレクトリーにも対応します。ページ移動はハッシュルーティングです。`bbs.cgi`など画面内のアドレスは演出であり、CGIサーバーは不要です。

## 構成

```text
index.html   共通レイアウト、ブラウザー風の外枠
style.css    個人サイト風の装飾、スマートフォン対応
app.js       全10画面、5つの謎、ヒント、進行保存、音声合成
favicon.svg  オリジナルの星アイコン
.nojekyll    静的ファイルをそのまま公開するための指定
TESTING.md   実施した検証と確認範囲
```

## 保存・音・アクセシビリティ

- かけら、クリア状態、閲覧済みヒント、BBSへの書き込み、演出設定は、このブラウザーのlocalStorageに保存します。BBSはゲーム内だけの演出で、ほかの利用者への共有や外部送信は行いません。
- 保存を禁止した環境では、タブを開いている間だけメモリーに保持します。探索メモから記録を消して最初から遊べます。削除前には確認画面が出ます。
- アクセスカウンターは固定の物語演出です。実際のアクセス数を収集しません。
- 音は初期状態でOFFです。「MIDI」は懐かしい表示名であり、実際にはWeb Audioでオリジナルの短いメロディーを合成します。タブが非表示になると停止します。
- 外部ライブラリー、外部フォント、外部画像、解析サービスに依存しません。初期の静的ファイル読み込み後、アプリから追加のネットワーク通信は行いません。
- キーボード操作、フォーカス表示、ダイアログのEscape終了、段階式ヒントに対応しています。隠し文字はタッチ向けのボタンでも表示できます。
- `prefers-reduced-motion`と画面上の演出OFFに対応します。星の記憶ゲームは、動きを減らす設定では静的な番号列で遊べます。

表示上の「IE 5.5推奨」は演出です。実際にはJavaScript・dialog・Web Audioなどを利用できる現代のブラウザーを対象としています。

サイト、登場人物、日付、架空の投稿はオリジナルのフィクションです。
